# ACE KING — мини-сайт для GitHub Pages

Готовый статический сайт на HTML и CSS. **Никаких сборщиков, ключей API, JavaScript-фреймворков и платных библиотек.**

## Как опубликовать

1. Создайте новый публичный репозиторий на GitHub, например `ace-king-website`.
2. Загрузите **содержимое** этой папки в корень репозитория: `index.html`, папку `assets`, `.nojekyll` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку **main**, каталог **/(root)** и сохраните.
6. GitHub Pages опубликует страницу по адресу вида `https://ВАШ-ЛОГИН.github.io/ace-king-website/`.
7. Проверьте результат с телефона, затем создайте QR-код **на окончательный адрес**.

## Как обновить расписание

Откройте `index.html`, найдите комментарий `Обновляйте даты и события здесь`. Замените строки внутри `events-grid`, а также федеральное событие под ними. Не забудьте поправить атрибут `datetime`.

## Как заменить фотографии

В папке `assets` находятся оригинальные фотографии клуба. Можно заменить файлы на новые с теми же именами (или поменять пути в `index.html`).

**Важно:** изображения выводятся с `width:100%; height:auto; object-fit:contain`, без `object-fit:cover` и фиксированной высоты. Поэтому браузер сохраняет исходные пропорции и не отрезает лица или края.

## Как изменить цвет, шрифты, отступы

Правьте `assets/styles.css`. Основные цвета задаются в начале файла, в селекторе `:root`.

## Кнопка записи

Сейчас кнопка ведёт на `https://vk.ru/ace_king21` — сообщество ACE KING. Для перехода в чат администратора или на форму заявки замените адрес ссылки в двух кнопках «ЗАПИСАТЬСЯ НА ИГРУ».

## Правила акции

В тексте используется предложение «Первая игра бесплатно». Перед публикацией проверьте, что оно действительно действует, и разместите доступные условия акции.

## Отображение на устройствах

- Телефоны от 280 px: одна колонка, крупные кнопки, карточки событий без горизонтальной прокрутки.
- Планшеты: две колонки для основного блока, затем адаптивная сетка.
- Компьютеры и широкие экраны: контент не растягивается более 1100 px.
- Изображения не обрезаются — можно видеть всю исходную фотографию, включая края.
- `viewport-fit=cover` учитывает безопасные зоны на мобильных устройствах.
